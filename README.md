# Projeto-de-BD
Projeto de conclusão do 4° Bimestre de Banco de Dados.

Este projeto consiste no desenvolvimento de um site de música, composto por três páginas interligadas, utilizando HTML, CSS, JavaScript e MySQL. Na primeira página, o usuário poderá realizar seu cadastro. Na segunda página, terá acesso a um formulário para adicionar informações sobre músicas, que serão enviadas e armazenadas em um banco de dados MySQL. Na terceira página, as músicas cadastradas serão exibidas em formato de biblioteca musical, permitindo que o usuário visualize todas as músicas que adicionou à sua biblioteca.
